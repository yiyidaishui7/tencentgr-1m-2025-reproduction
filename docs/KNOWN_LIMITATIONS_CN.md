# 已知限制与公开边界

本页集中记录会影响结果解释、复现或公开分发的限制。它不是免责声明，
而是面试与技术评审时应主动说明的证据边界。

## 1. 历史 Baseline 2×2 待重训

审计发现，历史训练路径在带用户特征时曾按事件重复插入用户 token，形成
`N+1` 个用户 token；评测路径每条序列只插入一个。该问题会同时影响历史
MM/no-MM、`maxlen=101/50` 四组训练，尤其使窗口长度对照混入了数据构造差异。

- `dataset.py` 已修复为每条序列最多插入一个用户 token；即使特征字典为空也保留
  用户 ID token。统一的截断函数会为它预留一个位置，再保留最近的 Item 历史。
- 回归测试覆盖非空/空用户特征、无特征 Item、训练/推理一致性和窗口溢出边界。
- 历史指标、预测和权重仅保留用于产物追溯；修复后的 2×2 尚未重训。
- 因此不得再把历史 no-MM50 写成最佳配置，也不得声称 maxlen 或多模态存在因果收益。

OnePiece 使用独立的数据与训练入口，不受这个 Baseline 缺陷影响。

## 2. OnePiece 证据范围

- 所有训练配置只有一个 seed。逐用户配对区间描述固定模型在当前 78,921 个评测
  用户上的差异，不等价于跨训练 seed 的稳定性。
- 4×128 到 8×512 同时改变深度和宽度，只能解释为当前预算内的整体容量扩展。
- SID 0.02 相对无 SID 的 +0.14% 只是点估计，区间跨 0；结论是“修复到统计持平”。
- 零碰撞 SID 是全局 residual 近似。容量修复移动了 766 个 Item，未严格保持上游
  文档所述的 L1 内 L2 层级约束。
- 当前公开仓库没有从原始向量端到端生成该 SID 映射的完整流水线，已发布内容主要
  验证训练、评测和结果契约。
- 全候选 Top-10 是分块精确内积；历史 Beam 指标与本轮对齐补充不是同一输出路径。

衍生补丁，仍需取得书面许可。本轮没有重写公开历史。

## 4. 复现与运行安全

- 原始数据约 137 GB、正式模型最高约 14 亿参数，本仓库不会在普通 CI 中重跑训练；
  CI 验证单元测试、语法和轻量契约。
- 公开依赖与测试入口记录在 `requirements-dev.txt`；NPU 路由代码存在，但没有在本
  仓库发布可核验的正式 NPU 训练结果。
- `pickle`、旧式 `.pt`/`torch.load` 产物可能执行不可信反序列化逻辑，只应加载可信
  来源；对外演示优先使用 SafeTensors 与 SHA-256 校验。
- `main.py` 的历史 checkpoint 命名和版本契约弱于 OnePiece 正式 runner；
  `model_rqvae.py` 是研究脚手架，不应描述为已完成的线上 SID 生成系统。

## 5. 可安全使用的面试结论

可使用：同预算 HSTU 相对 Transformer 固定 seed 点估计 +4.10%；HSTU 4×128 到
8×512 +25.63%；SID 碰撞从 2,250,041 降到 0，负结果从 -5.87% 修复到统计持平；
同 checkpoint 的 +2.61% 是评测协议效应。

不可使用：官方榜单成绩、稳定跨 seed 提升、完整复现 OnePiece 全部方法、SID 显著
提升、历史 no-MM50 最优、NPU 性能结论。
