# OnePiece 阶段复现结论与对齐差距审计

> README 主表的六行分数保留为已验真的**历史协议**结果：78,921 用户 ×
> 660,000 候选，包含 148,971 个训练索引冷候选，且没有过滤历史
> Item。2026-09-08 已补齐四套既有 checkpoint 的对齐重评，单独报告，

## 复现了什么

本项目复现的是 OnePiece 可在公开 TencentGR-1M 上审计的核心链路，而不是其全部赛后
系统：HSTU 序列编码、sample-bias-corrected InfoNCE、模型派生两级 SID、SID 辅助目标、
全局 residual 零碰撞近似映射，以及 SID Beam Search 后的双塔重排。额外完成 Transformer/HSTU
单变量对照和 4×128→8×256→8×512 容量实验。

这里的 SID **不是严格** README 层级算法：L2 是共享全局 residual 码本，容量修复还把
766 个 Item 跨 L1 移动，违反“SID1 固定”。冻结仓库没有提供 SID builder，因此只能
分别声明已验证的工程属性，不能声称 bit-exact SID 复现。

未复现或不声称对齐的部分包括完整比赛特征工程、上游过滤链、MoE、时间上下文、
24×512/12×1024 大配置和官方提交评测。因此本地 8×512 综合分 0.08346 与上游 README
的 HSTU 8×512 `0.1257` 不是同口径数字，不能计算“复现率”。上游冻结提交还报告
24×512 `0.1319`、MoE 8×512 `0.1300`、12×1024 `0.1371`，仅作为路线背景。参见
[OnePiece 冻结提交 README](https://github.com/shuoyang2/OnePiece/blob/73e51021dfafb75382baf9acd6a72ce47e5b705b/README/README.md)。

## 历史协议结果

- 最佳全候选点估计：无冲突 SID、权重 0.02，HR@10 **0.1207663**、NDCG@10
  **0.0666985**、综合分 **0.0834596**。
- 对无 SID 8×512：综合分 +0.0001138（+0.14%），配对 95% 区间
  [-0.0007888, 0.0010164]，结论为持平而非确定提升。
- 对第一轮碰撞/等权 SID：综合分相对恢复 **6.38%**。
- 最佳生成路径：权重 0.05 的 Beam 20×384，HR@10 **0.0323235**、NDCG@10
  **0.0220209**、综合分 **0.0252147**；目标生成召回 3.81%。
- 工程修复映射覆盖 4,783,154 Item，唯一 pair 4,783,154，碰撞 0；这不等于满足
  README 的 L1 内 L2 与 SID1 固定约束。

## 工程闭环

SID 权重 0.02/0.05 两套正式训练均完成
`metrics / predictions / model / history / config / log / SHA256SUMS` 归档，冻结协议与
78,921 行预测对齐经独立复算通过；这两次训练的远端临时输出在下载读回后清理。
公开仓库提供路径无关 runner、冻结配置、审计脚本、结果和文档；大模型及逐用户预测保存
在私有 Hugging Face 模型仓库。对齐候选评测契约保留原始 660,000 行输入审计，排除
148,971 个冷候选后在 511,029 个暖候选上评测，并记录 3,531,517 个被屏蔽的
用户-历史候选对。2026-09-07 对齐发布是非 Beam 控制组，因此 fallback 为关闭状态，
不宣称验证了 Beam 结果。

2026-09-08 的三次新增重评也已完成清单、数据集回执、权重及预测验证；公开补充
仅包含路径无关比较程序与标准 JSON 汇总，原始 checkpoint、逐用户预测和运行日志
不随公开 Git 仓库发布。本节不将本地验证等同于新的远端归档验收。

## 补充比较的复算入口

[`compare_onepiece_followup.py`](../scripts/compare_onepiece_followup.py) 接收四套既有
checkpoint 的历史/对齐产物目录，共八组输入；不训练模型，也不执行检索。每个目录
必须包含 SHA-256 清单及其全部文件，历史目录还必须包含清单绑定的 `model.pt`。
脚本核验权重绑定、冻结协议与逐行用户/目标/历史长度一致性，从预测重算整体和四个
历史长度分桶的指标、配对差值以及 mask × protocol 交互项，并输出不含私有绝对路径的
标准 JSON。

```bash
python scripts/compare_onepiece_followup.py \
  --historical-control ./artifacts/historical_control \
  --historical-mask ./artifacts/historical_mask \
  --aligned-control ./artifacts/aligned_control \
  --aligned-mask ./artifacts/aligned_mask \
  --historical-sid-002 ./artifacts/historical_sid_002 \
  --historical-sid-005 ./artifacts/historical_sid_005 \
  --aligned-sid-002 ./artifacts/aligned_sid_002 \
  --aligned-sid-005 ./artifacts/aligned_sid_005 \
  --expected-rows 78921 \
  --output ./metrics/onepiece_followup_comparison.json
```
