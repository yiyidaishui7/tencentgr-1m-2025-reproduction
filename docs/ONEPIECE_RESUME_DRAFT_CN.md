# OnePiece 简历项目终稿

## 项目名

**TencentGR-1M 大规模生成式推荐复现与 HSTU/SID 消融**

## 三条版

- 复现 OnePiece 的 HSTU + sample-bias-corrected InfoNCE 核心链路，在
  TencentGR-1M 的 100 万用户、478 万 Item 索引和官方 66 万候选上构建无泄漏最后
  点击评测；8×512 HSTU 固定 seed 达到 **HR@10 0.12082、NDCG@10 0.06651、
  综合分 0.08335**。
- 冻结 78,921 行评测协议，完成同预算 Transformer/HSTU 架构对照及
  4×128→8×256→8×512 容量实验：HSTU 相对 Transformer 提升 **4.10%**，8×512
  相对 4×128 再提升 **25.63%**；通过逐用户配对区间和历史切片约束单 seed 结论。
- 从训练后 Item Tower 生成两级语义 ID 并完成同规模消融，定位 SID 辅助损失在
  Epoch 3 后压过主任务、综合分下降 **5.87%** 的负结果；实现共享 GPU 原子断点、
  私有心跳、SHA-256 回读、预测行对齐、远端清理与 HF/GitHub 分层发布。

## 一句话版

完成最高 14.0 亿参数 OnePiece/HSTU 资源缩放复现、严格 Transformer 对照与模型派生
SID 消融；8×512 达到 0.08335 综合分，并将 SID 退化定位为损失平衡和 codebook
碰撞问题，形成可追溯的训练—评测—产物发布闭环。

## 不应声称

- 不写“官方榜单成绩”“比赛名次”或“完整复现 OnePiece 最终方案”。
- 不把固定人口配对区间描述成包含训练随机性的多 seed 显著性。
- 不把一次 SID 负结果描述为语义 ID 普遍无效。
